## 現在如何查看

開啟 [正式網站](https://jeffhsiao1122.github.io/bangkok-travel-guide/)，可以分享此網址，也可以從手機開啟。正式網站不需要啟動這台 Mac。

開發時仍可開啟 [本機網站](http://127.0.0.1:5173)。本機網址只適用目前這台電腦；兩個網址的行程保存空間分開，移轉時請先匯出再匯入。

如果之後無法開啟：

1. 在 Finder 開啟「桌面 → bangkok-travel-guide」。
2. 按兩下 `啟動網站.command`，保留它開啟的終端機視窗。
3. 在瀏覽器開啟上方本機網址。

啟動時沒有安裝軟體、登入、上傳行程或部署。若顯示連接埠已占用、工具缺少或 Mac 阻擋開啟，直接請 Codex 處理，不需自行修改程式。

## 建議先體驗這三件事

1. **自動排程**：填日期、人數、偏好、預算及必去／排除地點 → 產生 → 編輯 → 儲存。
2. **修改行程**：在每日安排中新增、更換、跨天移動、拖曳或按上移／下移；修改時間、停留分鐘與費用。鎖定活動會在單日重排時保留。
3. **查詢信用卡**：選「示範銀行」及示範卡片，體驗三種方案；選真實銀行則會如實顯示尚未收錄。

所有主要入口都可從上方導覽或網站地圖到達。小螢幕請點右上角選單按鈕。

## 行程保存與備份

- 行程與草稿放在目前瀏覽器、裝置及網站網域中，沒有帳號或雲端同步。
- 改動會保存草稿；「儲存行程」才會更新正式保存版本。
- 從「我的行程」可複製、刪除、查看、匯出全部或單份備份。刪除與清除前會要求確認，刪除後無法復原。
- 「匯出」會開啟備份視窗，提供下載 JSON、複製內容及查看內容。若瀏覽器不支援下載，可複製後另存為 `.json` 純文字檔。
- 「匯入 JSON 備份」會建立副本，不覆蓋已有行程；日期、格式及檔案大小都會檢查。匯入時重新計算預算。檔案選擇介面不支援時，可展開「貼上 JSON 備份內容匯入」。
- 詳細頁提供「列印／另存 PDF」，列印包含所有天數。實際 PDF 儲存由瀏覽器的列印介面完成。
- 上限為 100 份行程、單份備份檔 2 MB、每趟 1–14 天、每日至多 50 個活動。草稿保留最近 10 份。
- 清除瀏覽資料、無痕模式、不同瀏覽器、換裝置或改成正式網站網址，可能無法找到原本行程；請先備份再匯入。
