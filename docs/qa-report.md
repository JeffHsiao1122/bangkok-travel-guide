## 自動測試

Node 內建測試共 **28 項，全部通過**，沒有略過或失敗。涵蓋：

| 類別 | 檢查內容 |
|---|---|
| 日期與表單 | 無效日期、跨月／跨年、天數、人數、互斥必去／排除、每日可用時間 |
| 排程 | 必去優先、排除、不重複、營業星期、完整停留、關門前離開、無障礙未知不假裝符合、無法安排原因 |
| 預算 | 總額／每日上限、餐飲／門票／交通上限、按車與按人分攤、未知費用提醒；額外遍歷 88 組低預算條件 |
| 航班緩衝 | 深夜抵達、清晨起飛、沒有可安排時間時保留空檔，可正常保存 |
| 行程修改 | 單日重排保持其他天、避免重複、保留鎖定活動、固定時間衝突提醒 |
| 保存與匯入 | 讀寫往返、損壞資料保留、禁止保存時回報、複製獨立識別碼、版本與欄位驗證、UTF-8 實際大小、刪除後讀取、匯入重算預算 |
| 權益 | 不把示範當真實免費、有效期、會籍／消費條件未知、不符條件、合作缺漏、零次數及動線未知 |

測試原始碼在 `tests/core.test.js`；執行結果在 `docs/test-results.txt`。

## 網頁與尺寸巡檢

從網站地圖與實際頁面連結探索 **116 個網址**，包含 26 個主要入口、景點／餐廳／住宿／交通／地區詳情、貴賓室及示範卡詳細頁、推薦行程、文章與當時保存的私人行程。

每個網址分別在 390 × 844、768 × 1024、1280 × 900 檢查主標題及頁面寬度：**348 次巡檢，沒有缺少主標題或整頁橫向溢出**。完整路徑與結果保存在 `docs/route-checks.json`。後續新增的確認視窗與備份替代介面另外做了操作驗證。

另測 320 × 740 的首頁、排程、我的行程、編輯器、貴賓室與查詢工具，沒有整頁橫向溢出。比較表在手機內部可以橫向捲動，不把整頁撐開。手機選單能展開、導航後自動收起。這是瀏覽器尺寸模擬，沒有宣稱已使用實體手機／平板測試。

## 修正紀錄

- 中文主視覺在中等與手機寬度的換行。
- 編輯數字時保留暫時輸入內容，在完成輸入後驗證整數，避免清空欄位後立即跳回。
- 自行選擇用餐空檔不再重複收取交通費；加上 88 組條件的回歸檢查。
- 未設定預算的 `null` 不再在重排時被轉成零預算。
- 深夜抵達／清晨起飛的無活動日期保持有效範圍。
- 拖曳手把阻止與原生 HTML 拖曳搶事件，實際滑鼠排序成功。
- 攜伴權益與親子設施分開，信用卡比較補上更新／查證日期。
- 匯入拒絕不正確的偏好、地點、活動及日期資料，重新計算預算，不信任備份裡舊的總額。
- 備份加入可見內容、複製與貼上匯入，避開瀏覽器不支援檔案操作的情況。
- 原生確認視窗測試出現非預期 QA 副本移除，已從備份恢復。刪除、清除、縮短日期與重排改用網站模態視窗，取消經驗證保留原內容。
