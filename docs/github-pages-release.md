## 仍需知道的限制

- 尺寸模擬不等於實體手機或所有瀏覽器測試。Safari／Chrome 等跨瀏覽器、原生檔案選擇器、實際檔案下載及列印另存 PDF 尚未驗證；貼上備份匯入與可查看匯出內容已驗證。
- 此次沒有在正式網址按下刪除的最終確認；不能把全站巡檢當成每個按鈕的互動測試。其餘既有測試與限制見 [Phase 5 報告](qa-report.md)。
- 行程只保存在目前瀏覽器、裝置與網站來源；本機 5173、Pages 本機預覽 4173 與正式網站的保存空間分開。換網址前先匯出，再於新網址匯入。
- 分享首頁或推薦行程的 `#/` 網址可正常開啟；個人行程網址包含本機識別碼，別人的瀏覽器沒有該行程，並不等於公開分享功能。
- 目前沒有會員、雲端同步、自然語言 AI、即時機票／住宿／銀行資料或付款功能；聯絡管道待設定。
- 旅遊資訊仍為範例／預估／待確認；真實信用卡入場權益已查證 **0 筆**。查詢工具可體驗流程，不能作為實際入場資格依據。
- 合規複核是有範圍的盤點，不是完整法律保證。沒有新增外站擷取、爬蟲或資料 API；詳見 [來源與條款複核](compliance-review-2026-10-05.md)。未來真實來源、素材、商業用途或條款變更，需要重新核對。
