## 正式網站驗證

使用獨立 Chrome 瀏覽器、合成行程及隔離儲存空間，沒有讀取或改動使用者瀏覽器中的資料。390 與 1280px 都通過：

1. 非文字旅遊備註的檔案匯入被拒絕，顯示文字欄位錯誤。
2. 非文字活動類別的貼上匯入被拒絕，顯示活動格式錯誤。
3. 整批備份有任一格式錯誤時整批拒絕，等待錯誤訊息後確認原始保存字串不變；重新整理仍只有原行程。
4. 正常文字備份可匯入新副本，原行程逐欄不變；副本仍可開啟並編輯備註。
5. HTML 外觀及 javascript 外觀的合成備註呈現為原文字，不建立指定測試圖片或可執行連結，沒有執行測試事件。

兩種尺寸都沒有程式錯誤或非預期請求。正式 HTML 保留 no-referrer，主 JavaScript 與 CSS 的 SHA-256 均與本機已測版本一致。詳細合成結果只留在忽略上傳的 docs/local/import-safety/live-results.json 與 live-assets.json。
