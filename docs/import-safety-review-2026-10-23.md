# 行程備份匯入格式強化（2026-10-23）

狀態：本機修正與驗證完成後，已依使用者指示一次完成發布，見 [正式紀錄](import-safety-release-2026-10-23.md)。

## 問題與修正

重現既有 importTrips 接受非文字 options.note 與活動 type 的情況；這些物件可能在 React 畫面呈現時造成錯誤。未將此問題描述為已發現遠端程式執行或資料外洩。

驗證器補上選用旅遊文字欄位的型別與長度檢查，包括設定中的名稱、備註、住宿備註、區域、機場與起床偏好，以及自訂活動類別。缺省或 null 維持相容，原有正常文字、HTML 外觀字串及授權來源快照不會被刪改。失敗時顯示「行程文字欄位格式不正確」或原有「活動資料不正確」；整批驗證成功後才寫入本機保存。

未改變備份版本、匯入建立副本的行為或兩百萬位元組上限，不會自動清除、修復或改寫舊資料。已存在的異常本機資料仍由原有錯誤與原始備份復原介面處理，不宣稱本次可還原所有損壞備份。

## 驗證

- 51 項 Node 測試全部通過；新增 3 項涵蓋異常欄位、正常文字與來源相容、整批拒絕。
- Pages 建置、資源路徑及差異格式檢查通過。
- scripts/check-import-safety.mjs 使用隔離 Chrome 及合成行程，在 390 與 1280px 檢查：檔案與貼上錯誤皆拒絕、整批拒絕、原行程逐字不變、重整後仍僅原資料、正常備份可建立副本並編輯。
- 以 HTML 外觀的合成備註檢查 React 呈現為文字，不建立指定測試圖片或 javascript 連結，不執行測試事件，也無非預期請求。這是特定案例測試，不是完整滲透測試。
- 原有 6 組主要流程、117 個網址三種尺寸共 351 次檢查全部通過，沒有瀏覽器程式錯誤。涵蓋正常下載／檔案匯入、草稿還原、複製／刪除／清除、日期撤銷與單日重排。

公開合成測試結果：import-safety-checks-2026-10-23.json。詳細本機結果留在忽略上傳的 docs/local/import-safety 與 docs/local/import-safety-core。

沒有新增外部網站資料、爬蟲、套件、付費服務、銀行或個人資訊欄位。本批已依使用者確認公開發布。保留旅遊自由文字的選擇，不宣稱能辨識所有個資、惡意內容或第三方來源可信度。
