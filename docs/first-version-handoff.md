## 請用自己的裝置體驗一次（約 10–15 分鐘）

不需要提供任何個人資訊，也不需要開啟 GitHub 或輸入指令。

1. 用手機開啟正式網站，點右上選單，再進入「自動排程」。選擇旅遊日期與偏好，其餘可保留預設；按「下一步」至「產生行程並編輯」。
2. 在編輯器修改一項活動的停留時間，按「儲存行程」。重新整理，確認剛才的修改仍在。
3. 按「匯出備份」，下載 JSON 至自己的裝置。回到「我的行程」，以「匯入 JSON 備份」選取該檔，確認出現副本且原行程仍在。請自行保管檔案，不需將備份傳給開發者。
4. 開啟行程查看頁，按「列印／另存 PDF」，查看預覽是否包含所有日期。如果自己的瀏覽器支援，選擇另存 PDF；不必實際使用印表機。

完成後只需回覆「手機／電腦體驗正常」，或告訴我「在哪個頁面、按哪個按鈕、看到什麼」。不必提供私人備份、卡號、帳密或完整個人行程。不要為測試清除自己的既有資料。

這一項尚未由使用者完成確認，不預先標成通過。如果有裝置相容問題，先針對該問題修正，不擴增功能。

## 日後怎麼使用與維護

- **一般瀏覽**：直接使用正式網址，與這台 Mac 是否開機無關。
- **保留行程**：按儲存並定期下載 JSON；清除瀏覽資料或換裝置前先備份。PDF 是閱讀版，JSON 才能匯回繼續編輯。
- **換裝置**：在原裝置下載 JSON，移到新裝置，再於正式網站匯入。不同瀏覽器／網址各自保存，不會自動同步。
- **想修改網站**：直接說明要修改的頁面及預期行為；可由開發者檢查、修正、測試，你不用閱讀程式或執行 Git 指令。
- **想新增旅遊資料**：先提供想收錄的項目與來源線索，不要先下載未經授權的文章或照片。由開發者核對可用範圍；涉及費用、帳號、金鑰或授權疑慮時再由你決定。
- **想看本機預覽**：Finder → 桌面 → AI → bangkok-travel-guide → 按兩下「啟動網站.command」。保留開啟的終端機視窗，再開 http://127.0.0.1:5173 。正式網站不需這一步。
- **網站顯示異常**：先重新整理並確認是否使用正式網址；仍不正常時描述操作與錯誤訊息，交由開發者處理。不要自行刪除瀏覽器資料、專案、Repository 或執行不懂的指令。
- **發布**：改檔或推送不會自動部署，仍須明確確認本批公開範圍再手動發布。GitHub 登入、權限與付款由使用者操作；Token、密碼及私人備份不放進對話或公開專案。
