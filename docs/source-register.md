## 目前使用的內容

| 來源 | 使用方式與範圍 | 狀態 |
|---|---|---|
| 本專案自行建立的情境 | 景點時段／位置／費用、虛構餐廳與住宿、交通估算 | 明確標示範例／預估；非真實查證 |
| 使用者需求中的 BKK 品牌及銀行名稱 | 待核實分類與品牌清單 | 未聲稱仍營運、合作或免費資格；欄位待確認 |

| 自行撰寫一般教學 | 7 篇查詢／預約／比較核對步驟 | 沒有複製外部文章、銀行條文或旅客評價 |
| 內建 imagegen | 首頁曼谷主題插畫 | 標示 AI 插畫；特定據點實景照片未使用 |
| 本專案原創 SVG | 網站圖示、寺廟標誌及位置示意圖 | 非機場官方圖或真實道路導航 |

所有範例的 `confirmedAt` 都保留未知；資料建立日期不能當作銀行或營業現況的確認日期。
