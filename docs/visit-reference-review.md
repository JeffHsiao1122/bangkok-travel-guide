## 正確性與未採用欄位

- BACC、倫披尼公園、洽圖洽公園關閉時段有差異，保留未知。
- Jim Thompson 條目標示 2024-08；地址及車站註明日期，舊時段與列價不採用。
- 鄭王廟時段／列價缺少時效依據，渡船費用互相矛盾，不採用。未採用其精確門牌。
- BTS 日票、完整交通票表、列車分鐘數、渡船費用、首末班沒有可採用的當期依據，保留未知。
- Bangkok 文章的 DMK 機場段與鐵路段描述不一致；深紅線只列候選方案，不保證接續或當日服務。
- 部分大皇宮、臥佛寺、商場與 ARL 欄位可作為有來源的指南參考，但不宣稱當期有效；列價不代入預算、營業時段不代入排程。
- 入口、無障礙、個別店家／活動、票種與資格仍需另查；未知不是零元或免費。

本批沒有新增真實餐廳、飯店、機場貴賓室權益或信用卡方案。原有範例清楚保留；已查證真實信用卡入場權益仍為 0。
