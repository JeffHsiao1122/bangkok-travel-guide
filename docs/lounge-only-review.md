# 貴賓室專區範圍調整與驗證

日期：2026-10-23。狀態：已發布並完成正式網址驗證，程式版本 958e15cca1b95414a8a01099b64d67b7b558c32f。

依使用者要求，取消信用卡與銀行相關功能及銀行授權申請工作。移除卡片／銀行選單、卡片比較、入場權益判斷、示範卡及權益資料、貴賓室的持卡／免費／攜伴方案篩選，以及兩篇相關攻略。首頁、頁尾、網站地圖、旅遊總覽、FAQ 與來源說明同步更新。未寄送的銀行申請草稿與本次未提交研究檔已移除；既有歷史文件保留為歷史紀錄，不代表現行功能。

保留五項待核實品牌、三個清楚標示的虛構休息空間，以及位置、時段、設施篩選與比較；不新增或推測真實價格、營業、入場條件。一般準備清單不再涉及銀行方案。原有來源署名及 CC BY-SA 授權保留，未讀取新外部資料或照片。

舊 /credit-cards（包含子頁）、/lounge-finder、/guides/taiwan-cards、/guides/check-benefits 以取代歷史紀錄方式轉至 /lounges，丟棄原網址查詢參數，不回顯卡片參數。

## 驗證結果

- 47 項自動測試通過，包含所有主要頁面沒有指向已移除功能的入口，及原有排程、預算、儲存、匯出入測試。已移除的銀行服務專屬測試同步刪除。
- GitHub Pages 本機正式模式建置與資源路徑檢查通過。
- Chrome 隔離環境、本機網路限定：390、768、1280 寬度，9 個頁面共 27 次檢查通過，無水平溢出或已移除入口。
- 6 個舊網址（含查詢、比較、卡片詳細頁與兩篇舊攻略）轉向通過。
- 5 項互動通過：未知設施不判定可用、虛構示範設施篩選／重設、雙項比較、準備清單與重新整理清除、既有行程讀取及儲存原文不變。
- 瀏覽器無頁面執行錯誤；未使用真實使用者行程或瀏覽器登入資料。測試未對外聯絡。

初次瀏覽器驗證曾因未等待非同步路由更新，以及測試資料未採用正式儲存封裝而失敗；修正測試流程及樣本格式後，全套瀏覽器驗證通過。未為通過測試而降低網站檢查。
