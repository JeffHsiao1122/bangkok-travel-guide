# 行程檢查頁籤：本機審查

編輯日期：2026-10-25。狀態：取得使用者確認後已正式發布，見 [發布紀錄](trip-checks-release-2026-10-25.md)。

## 功能與操作

我的行程查看頁與編輯器新增「行程檢查」。依目前版本的活動快照與本站估算規則，集中顯示時間重疊／超出日程、未安排必去、未知活動費用、缺漏座標、營運未核實、範例活動、自行選店、預算超限、未填航班及機票住宿估算。每天均可按「查看第 N 天」回到對應時間表；查看頁需按既有「修改行程」才能編輯。

空白日可刻意留白，不當成錯誤；0 與未知費用分開。金額依有效活動與設定重新衍生，不使用過期總額，不改寫原始行程。編輯器依尚未正式儲存的目前修改更新提醒，查看已儲存版則依正式內容，按儲存後才更新該版。

檢查無分數、通行認證或「全部已查證」標記；沒有提醒仍不等於營運可行或資料完整。時間判斷使用本站交通估算，並非真實道路或班次。現有每日營運／時間提醒保留可展開閱讀。結果不自動加入 JSON 或 PDF，原有備份與列印行為保留。

## 來源與隱私

本批純粹整理本機資料，未新增外站擷取、API、套件、文章、圖片、評論、登入、定位、費用或個資必填欄位。沒有變更旅遊來源、來源版本、授權、讀取日期或營運確認狀態；既有 CC0／CC BY-SA 參考依原來源使用方式維持。

檢查僅唯讀計算，不自動儲存、刪除、遷移或重排活動，不因查看而產生草稿。舊行程保持原有資料；私人自訂文字只在使用者原本行程中呈現，沒有背景網路傳送。這些檢查不是全面資料正確性或法律保證。
