## 部署相容調整

Pages 模式使用 `/bangkok-travel-guide/` 資源前綴、HashRouter 與 `dist-pages/` 輸出。一般本機模式仍使用 BrowserRouter 與 `dist/`，避免破壞原本本機網址。圖示與首頁插畫改用建置前綴。跳至主要內容保留鍵盤入口，以程式移動到主要內容，避免 `#main` 覆蓋 HashRouter 頁面路徑。

新增手動 Pages 工作流程；只有在 `main` 分支、使用者手動執行並勾選公開確認後才建置及發布。沒有 push 自動發布、沒有第三方自建 Token。GitHub 主機政策連結與本機／正式儲存空間差異已加入隱私頁。

## 檔案與隱私檢查

`.gitignore` 已加入 `dist-pages/`、所有 `.env*`（含範本）、套件、憑證、登入設定、私密資料夾、行程匯出與本機資料排除項目。

新增 `scripts/security-check.mjs`，檢查常見 GitHub／API／AWS 金鑰、私鑰、含帳密網址、明文憑證欄位、個人電腦路徑與禁止上傳的檔案類型。只輸出檔名、行號與類別，不輸出疑似秘密值。`--staged` 直接讀取 Git 暫存區版本，避免檢查與預計提交版本不一致。

工作檔案掃描未發現上述格式的敏感值。推送前會再次掃描實際提交版本。這不是完整安全稽核，無法保證辨識任意格式的密碼、個資或素材權利。

來源文件的原始素材個人電腦路徑已移除。首頁 PNG 沒有文字／EXIF 中繼資料區塊；網站圖片與測試截圖仍需人工檢視公開範圍。Git 暫存區安全檢查結果見 `github-security-check.json`。
